# Noctaria Winter Invitation

A self-contained, responsive invitation reveal page.

## Use
Open `index.html` in a browser. Select the present to reveal the invitation. The prize area is editable in the page.

## Publish
This repository can be published with GitHub Pages:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for GitHub Pages to provide the public site URL.

The repository is currently private. Check your GitHub Pages plan/settings for private-repository publishing availability, or change the repository visibility to public if required.
